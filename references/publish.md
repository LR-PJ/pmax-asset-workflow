# 可选账户发布与失败恢复

仅在用户要求账户操作时执行。核定记录必须与当前素材、目标账户和操作范围一致；技能的加载、创意审核和其他项目的历史授权不构成当前发布授权。

## 连接与适配

优先采用当前环境可用且已授权的工具、连接器或 API。用户指定发布渠道时遵从；不绑定某个本机目录、令牌文件、开发者令牌来源或历史发布脚本。凭证不得复制到技能或交付目录。

本技能给出执行流程，不内置发布器或保证任何连接可用。需要编写适配器时，将账户、系列、资源组、商品范围、素材与信号作为输入，先查当前 API 版本和资源模型，再执行只读查询及可用的请求验证。连接不足时交付已完成的素材与配置，说明具体缺口，不声称已发布。

## 只读预检

1. 读取核定记录，核对素材存在、哈希和文案长度、目标状态、用户授权范围。
2. 核实目标客户、PMax 系列及资源组是否唯一，检查状态、必要设置与品牌素材关联层级。根据当前接口确认最小素材组合，不能仅按本地文件数推断。
3. 有商品 Feed 时，读取真实 Feed 条目，核实商品／变体、落地页、状态和销售区域。单品、多个变体和商品组分别记录，不由 SKU 猜测条目 ID；多候选仅在核定范围确为多商品时可接受。无 Feed 则跳过商品过滤步骤。
4. 核对 Logo、视频、商家名称、受众的实际对象和可用性；名称相似不代表可以复用。用户跳过视频人工预审不代表平台接受该视频或拥有使用权。
5. 检查现有同名对象和历史执行记录。对任何写入请求使用接口支持的验证模式；验证通过不代表正式提交或审核完成。

## 写入与恢复

- 保存操作计划和执行记录。优先创建暂停的目标资源组或按核定范围补全已有对象。更新已启用对象时，事先核定是否允许暂停及如何回退，避免擅自停用或破坏在投素材。
- 素材上传按内容哈希与账户查询定位已有对象，记录返回资源名；同名资源组需核对账户、系列、用途和内容，不盲目重建或覆盖。
- 按当前接口要求批量关联完整最小组合，避免逐条关联因暂时不满足要求而循环失败。Logo 等品牌资源应按账户采用的关联层级处理。
- 有 Feed 时建立准确的商品过滤：仅包含核定的条目／选择条件，按需要排除其余商品，并回查实际过滤树；不得把单品范围扩大为全商品。无 Feed 时不创建商品过滤。
- 设置已核定的搜索主题、受众与最终网址。改动仅限明确范围；不顺带更改系列预算、出价、地域、语言、转化目标或其他资源组。
- 回查素材类型和数量、网址、商品范围、信号及状态。授权仅到上传／暂停时保持该状态；授权启用且全部一致时才启用。
- 结果未知、超时或部分失败后先查询再补齐。设置有限重试；对象冲突、校验失败或事实不符时停止相关写入，保留状态和错误证据，不能无限重试或重复创建。新建未完成对象保持暂停；已有对象按核定的恢复方案处理，不擅自删除共享资产。

## 结果证据

写入后读取平台状态，记录时间与时区、客户、系列、资源组、Feed 范围（如适用）、素材资源名与数量、信号、完成步骤和错误。区分：

- 本地素材已完成。
- 账户素材已上传。
- 资源组已配置并暂停，或 `ENABLED`（已启用）。
- 平台返回的待审核／批准／拒登状态，以及对应层级。
- 有报表或平台证据支持的实际展示。

启用不能证明审核通过，审核通过不能证明已有展示。不将“符合投放条件”或某个资产的审核结果扩大解释成整个系列已展示。交付结果与可恢复执行记录；用户未要求持续监控时不自行创建监控任务。
