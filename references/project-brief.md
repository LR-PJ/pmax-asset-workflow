# 项目简报与通用参数

在当前项目的输出位置保存简报；目录和文件命名沿用该项目约定，不依赖本技能的安装目录。复用已有简报即可，无需为每轮局部修改重新建档。

| 项目参数 | 如何确定 |
|---|---|
| 品牌与主体 | 当前品牌名称、官网、商家名称、品牌指南及可用 Logo；区分品牌与具体产品名 |
| 产品或服务 | 链接、产品标识／型号／变体、真实售卖内容；服务则明确服务范围与地域 |
| 原素材与证据 | 原图、视频、规格、研究或认证资料；记录来源和冲突 |
| 市场与语言 | 目标国家／地区、投放语言、审核语言；不默认美国市场、某个年龄或性别 |
| 目标与受众 | 销售、询盘或其他目标；受众的任务、需求与购买障碍，区分已有结论与假设 |
| 品牌表达 | 语气、视觉风格、色彩、字体、允许与禁止主张；信息不足时提出有来源的临时方案 |
| 素材范围 | 图片、文案、配置，是否含视频制作、视频选用或发布；不把视频制作默认为图片任务的一部分 |
| 创意与画幅 | 建议主题数、母版画幅、需延展的比例、质量要求；默认提议六个主题，不强制数量 |
| 审核节奏 | 默认策略、首版、交付三阶段；记录用户合并／跳过的阶段及其适用范围 |
| 输出位置 | 当前项目的交付目录、命名与版本规范；正式文件与工作稿分开 |
| 发布配置 | 仅在需要上线时补齐连接方式、账户、系列、新建／更新资源组、Feed 模式和目标状态 |

信息优先级：用户当前明确指令、当前项目明确规则、当前品牌已确认资料、当前页面与原素材、标明依据的建议。品牌风格不能覆盖产品事实；证据冲突应单独解决，不靠优先级隐藏冲突。

能够影响创意或造成事实误导的缺口先问，例如产品版本无法识别、目标市场存在冲突、关键效果没有证据。账户 ID、视频或 Logo 的缺失通常可以稍后补，不必阻塞策略阶段。只有方案建议、尚未被用户选定的数量和风格，明确标为建议。

不需要询问与当前阶段无关的问题。优先从用户提供的来源和已连接的工具查找资料；没有资料时不假装了解该品牌。
