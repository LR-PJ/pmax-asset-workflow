# 正式交付与配置核定

## 本地素材交付

交付正式图片目录、文案复制表、素材清单、来源与质检记录，以及可回顾的策略和首版审核入口。沿用项目目录约定；正式素材与历史版本分开。文件名不携带别的项目的品牌、商品编号或日期。

文案字段按 [规格与文案](pmax-specs-copy.md) 校验，英文与中文分列；中文审核译文不得进入英文上传字段。清单中的最终图片须与实际文件、版本、哈希对应。仅制作部分素材时清楚说明范围，无需补齐未被要求的账户配置。

## 需要发布时的核定

收集可执行的最终值，而不是只写“使用原来的”：

| 配置 | 核实内容 |
|---|---|
| 连接与账户 | 已授权连接、目标客户；必要的管理账户关系，不记录令牌 |
| 系列与操作 | 现有或明确要求新建的 PMax 系列，新建或更新哪个资源组，允许改变的范围 |
| 目标状态 | 仅上传、配置后暂停，或配置后启用；明确用户授权来源 |
| 商品范围 | 无 Feed、单品、多变体或商品组；有 Feed 时记录真实商品标识或明确选择条件 |
| 链接 | 最终网址、语言与地区、相关跟踪参数；核对系列的网址扩展等设置是否影响实际落地页 |
| 素材 | 正式图与文案清单、商家名称、Logo、视频及其使用依据；缺失项标注处理方案 |
| 信号 | 核定的搜索主题、受众及其来源，不假定可复用历史受众 |
| 继承设置 | 展示现有系列预算、出价、转化目标、地域、语言及品牌设置等只读核实结果 |

没有要求更改的系列设置无需重新逐项审批。要改变系列级配置、现有共享对象或新建系列时，必须纳入当前明确范围并核定相应参数，不能借素材发布顺带更改。

## 持久记录

默认需要配置核定时提供可交互 HTML 页面，支持确认、调整、待核实、不适用、备注及 JSON 导出。现有后台表单、结构化文档或用户明确偏好能提供同等清晰记录时可替代；不把制作 HTML 当所有项目的必需步骤。

将最终决定保存到当前项目，使用 JSON 或同等结构化记录，并提供可读说明。浏览器 localStorage 只能暂存。核定记录包含记录版本、时间与时区、决定来源、执行值、待核实项、素材版本和哈希、发布范围与目标状态。用户在聊天中核定时，应据此更新项目记录，无需强迫其重复点击页面。

“调整”必须落实到执行值，“待核实”在相关账户写入前解决；免审项记录授权范围，不写成已审核。凭证保存在获授权连接中，不进入记录、技能或交付包。

素材或配置核定后再发生实质变化，应使受影响确认失效并重新核定该部分。无需重复确认没有变化的值。全部资料已足以执行且用户已授权时，直接继续对应工作。
