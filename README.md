# PMax 跨品牌素材工作流

适用于不同品牌和项目的 Codex 技能：根据产品链接、原图与当前品牌资料，完成 Google PMax（效果最大化广告）的策略规划、图片制作、文案、交付与可选发布。

## 工作流程

1. 产品事实、卖点、受众假设与创意规划。
2. 首版图片制作、逐张审核与修改。
3. 尺寸延展、中英对照文案、正式素材清单与配置核定。
4. 用户要求时，核实账户配置并执行发布与状态回查。

默认三阶段创作审核，可按项目明确合并或跳过。品牌、市场、语言、创意数量、画幅与商品范围均由当前项目确定。所有英文文案附中文对照，上传值与审核译文分开。

## 使用

将本仓库下载或克隆为名为 `pmax-asset-workflow` 的文件夹，放入你的 Codex 全局技能目录，或按当前环境的技能安装方式加载。保持 `SKILL.md`、`agents` 和 `references` 的相对结构。

在新项目中提供产品链接、原素材与品牌资料，并使用：

> 使用 `$pmax-asset-workflow`，根据本项目的产品链接、原图和品牌资料制作 PMax 图片与文案，默认三阶段审核。

完整入口见 [SKILL.md](SKILL.md)。

## 范围

本技能包含流程与参考资料，不内置账户凭证或通用发布程序。图片制作依赖使用环境中可用的生成或编辑工具；账户发布依赖当前获授权的连接，需在实际项目中验证。平台规格和政策在执行时以 Google 官方资料及账户响应为准。
